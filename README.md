# AppEscolhaAleatoria
Um aplicativo interativo desenvolvido em **Kotlin** que sorteia perguntas de forma aleatória, com foco em diversão e criatividade.

## Funcionalidades

* Sorteio aleatório de perguntas
* Categorias: **Diversão** e **Criativo**
* Animação de carta virando
* Fundo animado com bolhas
* Título com design clean e elegante

## Tecnologias utilizadas

* Kotlin
* Java Swing
* Graphics2D (renderização customizada)

## ▶️ Como executar

1. Abra o projeto no IntelliJ IDEA
2. Execute o arquivo `Main.kt`
3. Clique em **Girar** para sortear uma pergunta
